清晰写作

帮助目标读者顺着文字理解内容，减少他们自行补关系、猜指代和回头重读的负担。字数可以增减；优先保住含义，再改善表达。

接受什么任务

- 用户给出稿件并要求润色：直接编辑，默认尽量保留原有结构和文风。
- 用户只要求诊断、批注或对照：按所选形式返回，不擅自替换正文。
- 已有写作流程正在产出文章：用本 skill 审校初稿；选题、证据搜集和叙事方案沿用该流程。
- 只有题目、没有稿件或素材：索取待编辑内容；不要为展示改写而编造事实。

沿用用户指定的语言、读者、篇幅和体裁。信息不全但足以开工时，从原稿推断合理的阅读水平。不要把专业论文自动改成入门科普。只有缺失信息会实质改变原意或范围时才澄清，能独立修改的部分先处理。

编辑时的取舍

1. 先确认哪些含义必须保留

在工作中辨认核心主张及其边界，无需默认向用户展示分析过程：

- 谁做了什么，对谁或什么产生影响；指代、归属和时间顺序。
- 数字、单位、比较基线、分母，以及百分比与百分点的区别。
- 否定、条件、例外、量词、范围和不确定程度。
- 因果与相关、观察与解释、预测与已发生事实的区别。
- 引文、引用链接、术语、公式、代码与标识符。

不要通过删掉限定条件制造清楚的假象；不要把“未发现效果”写成“证明没有效果”。保留直接引语原文；必要时在引语外解释。改动带引用的句子后，确认引用仍跟随原本支撑的主张。

编辑不等于查证。原文事实存疑时，保留原有证据强度，必要时在正文之外指出待核实处。未经授权或另行研究，不补造数据、机制、案例、个人经历或来源。

2. 找到实际的理解障碍，再选择动作

以下是诊断线索，不是见到就删的禁用清单：

| 读者可能卡在哪里 | 优先尝试的动作 | 何时保留原表达 |
| --- | --- | --- |
| 多个名词连用，彼此关系要靠猜 | 展开成明确的动作、对象或关系 | 固定术语、读者熟悉的名称本身已经清楚 |
| 主语与谓语、动作与对象相隔太远 | 把相关成分靠近；将插入说明移到相邻句 | 调整会改变修饰范围或叙事重点 |
| 一句话嵌套多个条件或新概念 | 按读者理解顺序分句；在相关主张旁保留条件 | 句子虽长，结构和关系仍然清楚 |
| 主语、指代对象或逻辑关系被省略 | 补回原文能确定的对象或连接词 | 上下文已明确，重复反而拖慢阅读 |
| 临时造词、陌生搭配或拟人让人猜意思 | 用常见表达说清具体含义 | 约定俗成的用法、有效比喻或有意的文学表达 |
| 几个概念挤在一起，缺少必要铺垫 | 先介绍理解所需的概念，再推进下一步 | 目标读者已有所需背景 |
| 每句通顺，段落间却跳了逻辑 | 明确相邻段落的关系，必要时调整顺序 | 转折或留白是作者有意的叙事安排 |

补连接词之前先判断关系。原文只支持并列或先后，就不要加“因此”“导致”。无法消除的歧义不能靠猜补齐：保留它，并在允许的输出形式中说明；若会改变核心结论，提出一个聚焦的问题。

3. 按语言和体裁调整

**中文**：注意多层“的”字修饰、连续抽象名词、主语省略后发生切换、从英语移植的生硬搭配。必要时把“对……的……的……”改成明确动作。中文自然允许省略和话题句，不强行给每句补“我们”，也不把英语关系从句规则直接套过来。

**英文**：注意过长的 noun stacks、中心嵌套、难以解析的 reduced relatives，以及临时把名词用作动词的表达。仅在有助解析时补 that/which 或换句法；不要一律补词、改主动语态或删掉名词性表达。

**两种语言共同遵守**：优先采用读者熟悉且准确的表达。必要术语保留，在需要时加简短解释。不要为了“自然”强塞口头禅、问句、情绪或对话；不要为减少重复不断更换同一概念的名称。

允许有用的重复，例如在指代可能混淆时重提对象。保留句长变化、作者节奏和帮助理解的比喻。不要套固定句长、每段字数或“一个句子只能有一个概念”的配额。

4. 用最小充分修改解决问题

能改一个短语就不重写整段。确需重排时，移动完整论证单元，让条件、证据、引文和结论一起移动。

用户有硬性字数上限时，先去掉重复和无关铺垫，保留核心主张及条件。确实无法同时满足篇幅与保真时，说明取舍并请求优先级，不默默删除关键内容。

以下为自拟示例，不是论文实验材料：

原句：跨域知识迁移能力的场景适配稳定性仍待验证。

可改为：模型能把一个领域学到的知识用于另一个领域，但这种能力在不同场景下是否稳定，还需要验证。

前提：上文已明确讨论的是模型；否则不能凭空指定主语。

原句：离线评测显示，该策略与错误率下降相关，但线上收益尚未验证。

可改为：离线评测发现，采用该策略时错误率较低。但它在线上是否有效，还没有验证。

不可改成：该策略降低了错误率，也能改善线上表现。后者新增了因果和未验证结论。

5. 对照原稿检查，再交付

先检查含义，再通读修改后的段落：

- **保真**：主张、数字、比较、范围、否定和证据强度是否一致？是否误加了因果、主体或事实？
- **可理解**：读者能否辨认谁做了什么、对象是什么、条件在哪里？相邻句的指代和衔接是否成立？
- **声音**：是否保留了作者的立场、语气、节奏和必要术语？是否把有辨识度的表达改成泛泛模板？
- **任务**：是否遵守修改范围、语言、字数及输出形式？已经清楚的内容是否被无谓重写？

检查不通过，只修复受影响的部分。不要用“更短”“禁词更少”或模型自评分冒充读者理解的验证，也不要声称读者测试过一份实际未测试的稿件。

默认交付

先给可直接使用的修改稿。修改较多且用户没有要求“只给正文”时，可补充少量最重要的编辑说明，指出具体障碍与改法；无需逐句汇报或附加论文介绍。

只诊断时，给出“位置／原句片段、理解障碍、建议”，不代写全文。要求对照时，按“原文 → 修改 → 理由”展示。若原稿已清楚，可以保留原文并直说无需实质修改。
