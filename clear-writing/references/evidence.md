# 研究依据与适用边界

来源：Thomas Hikaru Clark、Matias B. Martin、Kyle Mahowald（2026），[Why is AI-generated language so hard to understand?](https://arxiv.org/abs/2610.29162v1)，arXiv v1。此处是简要转述；示例和编辑规则由本 skill 独立设计。

## 论文支持到哪里

- [实验 1，§3](https://arxiv.org/html/2610.29162v1#S3)：比较模型英语输出、人类语料及往返翻译后的改写，分析低频词组、依赖距离、宾语关系从句、名词堆叠、名词转动词和非生命主语搭配。结果随模型、场景和特征而变化。
- [实验 2，§4](https://arxiv.org/html/2610.29162v1#S4)：在 Qwen2.5-1.5B-Instruct 的受控任务中，长度惩罚改变了句法选择偏好，支持压缩压力可以影响表达形式的概念验证。
- [局限，§7](https://arxiv.org/html/2610.29162v1#S7)：分析限于英语、有限模型与对话种子；对前沿模型训练机制的解释依赖代理证据。

该研究没有直接验证本 skill 的改写能提升真人理解，也没有建立中文编辑阈值。不能据此断言所有模型都因同一种训练机制而变难读，或每次出现某个结构都应改写。

## 本 skill 做出的实践选择

把语言特征当成定位阅读障碍的线索，依据读者和上下文决定是否修改。主张保真、最小修改、作者声音保护、中文迁移及输出方式，均属于编辑设计。

不把往返翻译设为默认改稿流程：同义、语气和术语仍需逐一核对；论文使用它作为比较方法，并不替代编辑判断。

不把禁词计数、句长或可读性分数当作质量目标；短但省略关键关系的句子也可能难懂。

## 如何检验实际价值

先用 `../evals/cases.json` 检查是否保留数字、条件、引用、语气和任务范围。这能发现行为错误，不能证明真人读起来更轻松。

若要验证读者收益，可让目标读者在不知道版本来源的情况下阅读同类文本的不同版本，比较核心观点复述、条件理解、事实错误、回读需求和阅读耗时。交叉分配版本，避免同一个人先读原稿再读修改稿造成熟悉效应。把文风偏好与理解表现分开记录。
